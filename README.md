## 🚀 Featured Project

### [OVR.lol](https://github.com/adamkorompai/OVRlol) - Real-Time Game Analytics Engine

A high-throughput, event-driven analytics engine for real-time Riot Games match tracking.

**Architecture & Key Features:**
- **Hexagonal Architecture** to decouple domain logic from infrastructure (Kafka, external APIs)
- **Event-driven pipeline** using Apache Kafka for high-throughput player metrics processing
- **Real-time updates** streamed to clients via WebSockets
- **Reliability patterns** including idempotent consumers and Dead Letter Queues (DLQ)
- **Tech Stack:** Java 17, Spring Boot, Apache Kafka, WebSockets, PostgreSQL, Docker
- **Frontend:** Reactive Angular dashboard for live visualization

*This project demonstrates my ability to design and implement complex, production-ready systems independently.*
